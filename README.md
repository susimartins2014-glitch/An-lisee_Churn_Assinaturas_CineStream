# 🎬 CineStream — Dashboard de Análise de Churn de Assinaturas

> ⚠️ **Nota:** Este projeto utiliza **dados fictícios** de uma empresa fictícia (**CineStream**), desenvolvidos exclusivamente para fins de estudo e composição de portfólio em Business Intelligence

---

## 📌 Sobre o Projeto
O objetivo do painel é analisar a taxa de cancelamento (**Churn**) de uma plataforma de streaming, fornecendo indicadores para identificar padrões de cancelamento precoce, comportamento por plano e motivos de perda de assinantes

---

## 📊 Principais Indicadores e Visuais

* **Métricas Principais (Cards):** Total de churns, permanência média geral, média de churn precoce no Q1 e principal gargalo de cancelamento.
* **Permanência Média por Plano:** Gráfico de barras comparando a retenção entre os planos Premium, Padrão e Mobile.
* **Quartis de Churn x Plano:** Matriz/mapa de calor que cruza a permanência dos usuários por quartil e tipo de assinatura.
* **Motivos de Cancelamento:** Gráfico de rosca detalhando as razões de churn (preço, catálogo, interface e suporte).
* **Painel de Observações:** Resumo em texto dos principais *insights* do relatório.

---
## 🛠️ Tecnologias Utilizadas

* **SQL** (Consulta e estruturação das bases de dados)
